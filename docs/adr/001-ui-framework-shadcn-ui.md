# ADR-001: UI フレームワークに shadcn/ui を採用

## ステータス
承認（Accepted）

## 日付
2026-05-09

## 背景

ライフプランニングアプリ（hizamaru）のフロントエンド UI コンポーネントを効率的に実装するため、UI フレームワークの選定が必要である。

Next.js 16（App Router）と Tailwind CSS を基本技術スタックとしており、これらと相性が良く、開発速度とカスタマイズ性のバランスが取れたフレームワークが必要。

## 候補と評価

| フレームワーク | 学習曲線 | カスタマイズ | Next.js 統合 | 評価 |
|-----------|--------|---------|----------|------|
| **shadcn/ui** | ★★☆ やさしい | ★★★ 高い | ネイティブ | ⭐⭐⭐ |
| Material-UI | ★★★ 難しい | ★★☆ 低い | 別設定が必要 | ⭐⭐☆ |
| Chakra UI | ★★☆ やさしい | ★★★ 高い | 別設定が必要 | ⭐⭐⭐ |
| Headless UI | ★★★ 難しい | ★★★★ 最高 | 別設定が必要 | ⭐⭐☆ |

## 決定

**shadcn/ui を採用する。**

## 理由

### 1. Tailwind CSS ネイティブ
- shadcn/ui はすべてのコンポーネントが Tailwind CSS で実装されている
- CSS 変数で色、サイズなどを簡単にカスタマイズ可能
- Next.js のデフォルト CSS フレームワークである Tailwind CSS との統合が完璧

### 2. コピー・ペースト型アーキテクチャ
- npm install ではなく、コンポーネントコードをプロジェクトにコピーして使用
- 詳細な実装が明確で、デバッグやカスタマイズが容易
- ベンダーロックインがない

### 3. 学習曲線が緩い
- React コンポーネント型で直感的
- ドキュメントが充実している
- コミュニティが活発で、問題解決がしやすい

### 4. hizamaru のデザイン要件に適合
- ダッシュボード、タイムライン、フォームなど基本的な UI コンポーネントが揃っている
- 複雑なカスタマイズが必要な場合も、Tailwind CSS でカバーできる

### 5. 開発速度
- セットアップが簡単（`pnpm exec shadcn-ui@latest init`）
- プロトタイピングから本実装までスムーズに進められる

## 影響

### ポジティブ
- 開発速度の向上
- コンポーネント実装の一貫性
- カスタマイズ・メンテナンスの容易さ

### ネガティブ
- 開発チーム全体が Tailwind CSS の理解が必要
- コンポーネント数が増えるとコードベースが大きくなる可能性

## 代替案

### Material-UI
- 不採用とした理由：デザインが固い、カスタマイズが限定的

### Chakra UI
- 不採用とした理由：shadcn/ui とほぼ同等だが、Tailwind ネイティブではない

## 次のステップ

1. `pnpm exec shadcn-ui@latest init` でセットアップ
2. 必要なコンポーネント（Button, Input, Dialog など）をインストール
3. テーマカラーに合わせて `globals.css` をカスタマイズ
